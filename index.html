Nuova classe

Se una riga comincia con un numero, uso quel numero; altrimenti numero in ordine. Il numero è ciò che collega l'osservazione allo studente nel foglio.

Classi sul dispositivo

Esporta per il foglio

Osservazioni rapide della griglia. Il file contiene classe, data, numero, segni e annotazioni, non i nomi. Importalo nel foglio della classe con Valutazione › Importa dall'iPad. Puoi esportare quante volte vuoi: le righe già importate vengono aggiornate, non duplicate. Le sessioni di attività si esportano dalla scheda Attività.

Copia di sicurezza

Tutto ciò che c'è sul dispositivo, nomi compresi, in un file da tenere sul Mac. Serve a ripristinare i dati se l'iPad li perde o se cambi dispositivo.

Dove stanno i dati

Solo nella memoria di questo dispositivo: nessun invio in rete. Se cancelli i dati dei siti di Safari, o disinstalli l'icona dalla schermata Home, si perdono: per questo c'è la copia di sicurezza.
